# Mohamed Elhosiny — Portfolio

Personal portfolio website for **Mohamed Said Mohamed Elhosiny**, Aspiring AI Engineer focused on NLP, Generative AI, and applied machine learning.

## Tech Stack

- **Next.js 16** (App Router, Turbopack, `next/image`)
- **Tailwind CSS v4**
- **Motion** (`motion/react`) — cohesive UI entrances, hover/tap physics, and navigation indicators
- **GSAP + ScrollTrigger** (lazy-loaded) — scrubbed section transitions and directional navbar wipes
- **Lenis** — smooth scrolling synced to a single RAF loop

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Scripts

- `npm run dev` — start the local development server
- `npm run build` — build for production
- `npm run start` — run the production build locally
- `npm run lint` — run ESLint
